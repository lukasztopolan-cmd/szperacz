🔑 Jednorazowo: utwórz token fine-grained:

2. Repository access → Only select repositories → wybierz szperacz
3. Permissions → Repository permissions → Contents: Read and write oraz Actions: Read and write
4. Generate token → skopiuj (zaczyna się od github_pat_...)
